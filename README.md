# 📚 Biblioteca Minuto

Aplicação desktop desenvolvida em **C# e Windows Forms**, com o objetivo de praticar fundamentos da programação orientada a objetos (POO), manipulação de dados e operações CRUD.

O projeto simula um sistema simples de gerenciamento de biblioteca, permitindo cadastrar, consultar, pesquisar e remover registros de livros por meio de uma interface gráfica.

## 🖥️ Tecnologias utilizadas

- **C#** — linguagem de programação.
- **.NET 6** — plataforma de desenvolvimento.
- **Windows Forms** — construção da interface gráfica.
- **Visual Studio** — ambiente de desenvolvimento.

## ⚙️ Funcionalidades

- [x] Cadastro de livros.
- [x] Listagem de livros cadastrados.
- [x] Pesquisa de livros por título.
- [x] Seleção e visualização de registros.
- [x] Remoção de livros.
- [ ] Persistência dos dados em banco de dados.

## 🧠 Conceitos praticados

Durante o desenvolvimento, foram trabalhados conceitos fundamentais de programação:

- Fundamentos de C#.
- Introdução à programação orientada a objetos (POO).
- Manipulação de listas e coleções.
- Estruturas condicionais e métodos.
- Tratamento de eventos em Windows Forms.
- Manipulação de componentes visuais.
- Operações CRUD (Create, Read, Update e Delete).

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/GervasioLopes/Biblioteca-Minuto.git
```

2. Abra o arquivo `Biblioteca minuto.sln` no Visual Studio.

3. Aguarde a restauração dos componentes necessários.

4. Execute a aplicação utilizando `F5` ou o botão **Iniciar** do Visual Studio.

### Requisitos

- Windows.
- Visual Studio 2022 ou compatível.
- .NET 6 SDK.
